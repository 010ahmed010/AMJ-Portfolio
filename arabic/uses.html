الأدوات التي أستخدمها

نظرة شاملة على الأجهزة والبرامج والأدوات التي تُشكّل بيئة عملي اليومية — كل ما أعتمد عليه لبناء تجارب ويب متميزة.

المحرر والطرفية

Visual Studio Code

محرري الأساسي. سريع وقابل للتخصيص ومليء بالإضافات المفيدة. أقضي معظم يومي هنا.

Zsh + Oh My Zsh

شِل متطور مع إضافات للـ git والإكمال التلقائي وتمييز الصياغة. يجعل الطرفية تجربة ممتعة فعلاً.

Fira Code

خطي المفضل للكود مع ربطات رسومية جميلة. يتناسق تماماً مع أي ثيم داكن.

One Dark Pro Theme

ثيم داكن مريح للعين بتباين ممتاز. الخيار الأمثل لجلسات البرمجة الطويلة.

أدوات التطوير

Git & GitHub

التحكم بالإصدارات في كل شيء. أعيش في الـ branches والـ pull requests ورسائل الـ commit.

Vite

أداة بناء وخادم تطوير فائقة السرعة. استبدلت Create React App في جميع مشاريعي — لا رجعة.

Postman

اختبار وتوثيق الـ API. لا غنى عنه عند بناء أو استهلاك REST APIs.

npm / pnpm

إدارة الحزم. أُفضّل pnpm لسرعته وكفاءته في استخدام القرص خاصة في المشاريع الكبيرة.

الأُطر والمكتبات

⚛

React.js

إطار الواجهة الأمامية الأساسي لديّ. مبني على المكونات، سريع، ومنظومته هائلة.

▲

Next.js

لتطبيقات React الإنتاجية التي تحتاج SSR أو SSG أو مسارات API متكاملة.

Tailwind CSS

CSS قائم على الأدوات. لا أتخيل التنسيق بدونه الآن — أصبح جزءاً لا يتجزأ من سير عملي.

Node.js + Express

الخلفية المفضلة لديّ لبناء REST APIs والمنطق الخادمي. مثالي لمشاريع MERN.

MongoDB

قاعدة بيانات NoSQL مرنة لمعظم مشاريع الخلفية. تتكامل بشكل طبيعي مع Node.js عبر Mongoose.

Redux Toolkit

إدارة الحالة لتطبيقات React المعقدة. RTK جعل Redux ممتعاً في الكتابة فعلاً.

التصميم

Stitch

تصميم UI/UX والنمذجة. أضع الإطارات الأولية قبل كتابة سطر كود واحد.

Unsplash + Lucide Icons

صور عالية الجودة مجانية ومكتبة أيقونات نظيفة — عنصران أساسيان في أي مشروع واجهة.

الاستضافة والنشر

▲

AWS

خياري لتوسيع تطبيقات MERN. تحكم كامل بـ Linux VPS واستقرار سحابي عالٍ.

GitHub Pages

مثالي لاستضافة المواقع الثابتة ومعارض الأعمال مباشرة من GitHub — مجاني وسريع.

Netlify

لاستضافة المواقع الثابتة مع معالجة النماذج والدوال اللاخادمية عند الحاجة.

الأجهزة

لابتوب التطوير

جهازي الرئيسي لكل عمل التطوير — ذاكرة وفيرة ومعالج سريع لضمان سلاسة الأداء.

Debian Linux

نظام التشغيل المفضل لديّ. مستقر وسريع ويمنحك تحكماً كاملاً في بيئة التطوير.
